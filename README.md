# Leetcode Daily

## Goal

Practice algorithm problems and build reusable problem-solving patterns.

## Structure

* `problems/` → individual problems
* `patterns/` → reusable patterns (sliding window, binary search, etc.)
* `templates/` → code templates

## Workflow

1. Solve problem in VSCode
2. Write notes (approach, mistakes, pattern)
3. Commit
4. Revisit next day

## Rules

* Focus on understanding, not quantity
* Extract patterns after solving
* Re-write problems after 1 day
